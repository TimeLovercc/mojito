# Research rules (example)

`MOJITO_RESEARCH_RULES` in `worker/.env` points at a Markdown file that every Idea Lab research run reads. Point it at the rules your own sessions already follow (for example your global `CLAUDE.md`), or start from this file.

- Work in this order: check the effect is real, check the measurement can be trusted, find the layer where it lives, then change something.
- Keep observation, hypothesis, evidence, intervention and result apart. A plausible hypothesis is not a diagnosed cause; a planned step is not a finished one.
- Treat metrics, judges, losses and baselines as instruments that can be wrong; validate them before optimizing what they report.
- Compare like with like: same data, same budget, same exposure. Small runs screen a claim; claims about scale or transfer need matching evidence.
- Report progress in one sentence: which controlled variable changed and which measured result moved. If that sentence cannot be written honestly, say the change is not attributable.
- Every paper you cite needs a locator you actually opened (arXiv or DOI).
- Never invent results, citations or earlier opinions. Unknowns stay marked unknown.
- Stay inside the authorized budget; new spending, new hardware or stopping a whole project is the owner's decision.
